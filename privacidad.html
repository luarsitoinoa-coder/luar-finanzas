Política de privacidad

Luar Finanzas

Última actualización: 16 de noviembre de 2026.

1. Información general

Luar Finanzas es una aplicación de administración de finanzas personales. Esta política explica cómo se recopila, utiliza y protege la información de sus usuarios.

2. Información que podemos utilizar

La aplicación puede utilizar información de perfil de Google, información financiera introducida por el usuario y, cuando esté habilitada la función correspondiente y el usuario lo autorice, información de notificaciones bancarias recibidas mediante Gmail.

3. Uso de Gmail

La conexión con Gmail será opcional. Si el usuario la autoriza, Luar Finanzas utilizará el permiso de lectura de Gmail para identificar notificaciones relacionadas con las entidades financieras que el usuario haya seleccionado.

La finalidad será identificar datos de movimientos, como importes, fechas, descripciones y tipos de transacción, para facilitar su registro en la aplicación.

El permiso técnico de Google puede permitir el acceso a otros mensajes de Gmail. La aplicación está diseñada para procesar únicamente los mensajes necesarios para la función financiera.

La conexión con Gmail no estará activa hasta que se implemente y se solicite la autorización correspondiente.

4. Uso de la información

La información se utilizará para mostrar movimientos, organizar cuentas, calcular balances y generar reportes financieros personales.

5. Protección de los datos

Luar Finanzas está diseñada para mantener los datos de cada usuario separados mediante su cuenta. Se aplicarán medidas técnicas y organizativas razonables para proteger la información.

6. Compartición de información

No vendemos la información personal de los usuarios. Los proveedores tecnológicos necesarios para operar la aplicación podrán procesar información conforme a sus condiciones y políticas de privacidad.

7. Conservación y eliminación

La información se conservará mientras sea necesaria para ofrecer las funciones de la aplicación o hasta que el usuario solicite su eliminación, de acuerdo con las posibilidades técnicas y obligaciones aplicables.

8. Revocación del acceso a Google

El usuario podrá retirar el acceso de Luar Finanzas a su cuenta de Google desde la configuración de seguridad de su cuenta. La revocación impedirá nuevas lecturas autorizadas.

9. Contacto
